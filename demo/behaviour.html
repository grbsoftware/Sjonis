Why native <dialog>
The platform supplies a focus trap, an inert background, Escape handling and top-layer stacking. Hand-rolled modals get one of those wrong.
Why not the popover attribute
Same class of problem as halo's backdrop-filter — WebKitGTK, which Tauri uses on Linux, is unreliable here. Menus are positioned by script instead.
Why a classic script
ES modules are blocked on file://. Double-clicking a single .html file has to keep working.
